# AI-Driven Harmonization in Pharma

> **Companion code for:** [Bridging the Data Divide: AI-Driven Harmonization in Pharma](https://alishahmohammadi22.github.io/blog/ai-driven-harmonization-pharma.html)
>
> *Ali Shahmohammadi, Ph.D. · January 2026*

A fully reproducible Python pipeline that harmonizes messy multi-site laboratory data to [LOINC](https://loinc.org) — the public Logical Observation Identifiers Names and Codes standard maintained by the Regenstrief Institute.

---

## What this does

The pipeline simulates a real data-pooling problem: **9,280 lab results from three source systems** (a legacy EHR, a CRO reporting in SI units, and a partner lab), each recording the same eight analytes under different local names, units, and formatting conventions.

It harmonizes that messy data in **four deterministic steps**:

1. **Normalize** — strip whitespace, lowercase, remove punctuation
2. **Dictionary lookup** — match against an ontology-style LOINC synonym map
3. **Fuzzy semantic match** — `difflib.get_close_matches` for near-misses (≥82% similarity)
4. **Unit conversion + flag** — convert every value to the canonical LOINC unit; flag anything unresolved for human review rather than silently guessing

### Results

| Metric | Before | After |
|--------|--------|-------|
| Distinct raw term strings | 44 | 8 LOINC concepts |
| Unit representations | 11 | 5 canonical units |
| Auto-mapping coverage | — | **98%** (96.3% dictionary · 1.6% fuzzy) |
| Mapping accuracy vs ground truth | — | **99.9%** |
| Cross-site findability | **34.8%** | **99.9%** |

The 2% that couldn't be auto-mapped were **correctly flagged for human review**, not silently guessed.

## Quickstart

```bash
# Clone
git clone https://github.com/alishahmohammadi22/ai-driven-harmonization-pharma.git
cd ai-driven-harmonization-pharma

# Install dependencies
pip install -r requirements.txt

# Run the full pipeline
python harmonize.py

# Run tests
pytest tests/ -v
```

The script writes two CSVs (`data/raw_pooled_lab_data.csv` and `data/harmonized_golden_dataset.csv`) and prints a metrics report to stdout.

## Key design choices

- **Deliberately simple matching logic** — the value comes from harmonization, not from a sophisticated model. `difflib` + a curated synonym dictionary gets you 98% coverage.
- **Refuse rather than guess** — records that can't be mapped above the confidence threshold are flagged for human review, preserving scientific correctness.
- **Real LOINC codes, simulated data** — all LOINC codes and canonical names are from the actual public standard. No patient data is used anywhere.
- **Fully reproducible** — seeded RNG (`numpy.random.default_rng(42)`) ensures identical output every run.
